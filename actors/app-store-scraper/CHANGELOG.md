# Changelog

## 0.1.0 (2026-11-20)

- First release: Apple App Store search by keyword, app lookup by URL, id or bundle id, and every app of a developer, in any country, from Apple's official iTunes Search and Lookup APIs. Name, developer, price, rating and rating count (overall and current version), version, release dates, size, genres, content rating, languages, icon, screenshots, description and release notes. Calls are paced to Apple's documented limit of about 20 per minute.
