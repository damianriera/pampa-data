# Changelog

## 0.1.0 (2026-11-12)

- First release: autocomplete suggestions from Google Search, YouTube and Bing for up to 1,000 seed keywords per run, in any language and country. Optional A to Z, question word and preposition expansion (English, Spanish, Portuguese, French, German, Italian) and custom modifiers with a `{keyword}` template. One item per unique suggestion per keyword and source, with the typed query and position; seed keyword excluded by default; per-keyword cap; optional proxy.
