# Changelog

## 0.1.0 (2026-11-23)

- First release: bulk on-page SEO audit for a list of URLs or every page of a sitemap (indexes, gzip and text sitemaps, found from robots.txt). Per page: status code, full redirect chain, response time, title and meta description with lengths, canonical, meta robots and X-Robots-Tag, robots.txt check for Googlebot, indexable flag, hreflang, H1/H2 and heading counts, word count, Open Graph and Twitter tags, JSON-LD types, image alt coverage, link counts (optional link lists) and a list of issues. A SUMMARY record adds issue counts and duplicate titles and descriptions across the run. Blocked pages (401/403/429/503), files that are not HTML pages and network errors are not charged.
